# Project Roadmap

## Mental Health Specialists in Iberoamerica — Development Roadmap

**Repository:** juanmoisesd/mental-health-specialists-iberoamerica  
**Last Updated:** May 2026

---

## Vision

Transform from a descriptive open dataset into a **comprehensive scientific observatory** for mental health workforce policy in Ibero-America — comparable to IHME, WHO Observatory, or PAHO PLISA in analytical depth.

---

## Completed ✅

### Phase 1: Foundation (2025 Q1)
- [x] Core dataset: specialist density for 22 countries (2000–2026)
- [x] FAIR compliance: schema.json, datapackage.json, CITATION.cff, PROVENANCE.md
- [x] Interactive dashboard (GitHub Pages)
- [x] Zenodo archival (DOI: 10.5281/zenodo.18984813)
- [x] Country-level HTML mini-papers (22 countries)
- [x] Hugging Face dataset card

### Phase 2: Scientific Depth (2025 Q2–2026 Q2)
- [x] Central CSV dataset (`data/specialists_data.csv`)
- [x] Socioeconomic overlay (`data/external_indicators.csv`)
- [x] Workforce Gap Index (WGI) calculation
- [x] Advanced analysis notebook (`notebooks/02_advanced_analysis.ipynb`)
- [x] Executive Summary Dashboard (`executive_summary.html`)
- [x] Policy Brief (`POLICY_BRIEF.md`)
- [x] Methodology document (`METHODOLOGY.md`)
- [x] Data Sources inventory (`DATA_SOURCES.md`)
- [x] Multilingual support (EN/ES/PT)
- [x] Choropleth map (Leaflet.js)
- [x] Policy impact simulator
- [x] OECD benchmarking radar charts
